## Почему 1201 — это не «треть от 5000»

Oxford 3000 и Oxford 5000 **не складываются**: 5000 уже включает 3000. Целевой объём —
**5000 уникальных слов**, а не 8000. Значит покрытие сейчас ≈ **24 %**.

Распределение по уровням в самих списках Oxford примерно такое:

- Oxford 3000 (A1–B1) — ~2500–2700 слов
- Oxford 5000 (дополнение B2–C1) — ~2000–2300 слов (пометки `*` у 690 наиболее важных слов B2–C1)

## Как продолжить

Новая колода = один файл `<уровень>/<тема>.md`. Слова лучше брать пачками по 40–60 на тему
и сразу сверять с существующими файлами, чтобы не плодить дубли:

```bash
python3 - << 'PY'
import re, glob, collections
w=collections.Counter()
for f in glob.glob("*/*.md"):
    for b in re.split(r"(?m)^## Карточка\s*$", open(f,encoding="utf-8").read())[1:]:
        m=re.search(r"(?m)^Front:\s*([^—]+?)\s+—",b)
        if m: w[m.group(1).strip().lower()]+=1
print("слов:",len(w),"| дублей:",sum(v-1 for v in w.values() if v>1))
PY
```
